# human_2_KKS_pipeline

このツールは、次の流れを1つのGUIでつなぐためのアプリです。  
`音声/外部テキスト -> 文字起こし -> テキスト変換 -> Grok/SBV2 -> KKSへ送信`

英語版は [README_en.md](README_en.md) を参照してください。

## 1. 最初の起動

1. `setup.bat` を実行（初回のみ時間がかかります）
2. `launch.bat` を実行
3. GUI上部の `KKS起動中` をON
4. `開始` を押す

一時停止は `一時停止`、完全停止は `停止` を使います。

## 2. 画面構成

### 上部エリア
- `KKS起動中` トグル
- `開始 / 一時停止 / 停止`
- 手動テキスト送信欄（`送信`）

### 録音設定 タブ
- 入力デバイス
- WAV保存先
- 閾値 / 無音停止秒数
- 最小保存秒数
- 開始前バッファ / 停止後余韻

### パイプライン設定 タブ
- KKSフォルダ
- 出力先
- 保存設定
- FasterWhisper 設定
- Grok/TTS Python
- SBV2フォルダ / モデル / サーバーURL
- 送信設定（pipe, host, port, endpoint, token）
- 字幕送信設定
- 外部テキスト受信設定

### 変換辞書 タブ
- 通常テキスト用の変換ルール表

### 文字起こし変換 タブ
- 文字起こし直後に適用する変換ルール表

### Selenium タブ
- Chrome起動 / 接続 / 終了
- Grokテスト起動

### フィルター タブ
- 除外フレーズ管理

## 3. source_mode

- `external`: 外部テキスト中心（WAV入力は無視）
- `mic`: マイク録音中心（外部受信サーバーは起動しない）
- `both`: 両方受け付ける

## 4. 保存設定（デフォルト）

初期値は「txtだけ残す」設定です。

- `録音WAV保存`: OFF
- `SBV2音声保存`: OFF
- `転写txt保存`: ON
- `SBV2 txt保存`: ON

つまりデフォルトでは、音声系の生成物は処理後に削除されます。

## 5. 出力先構成

設定した `出力先` 配下に主に以下が作られます。

- `transcripts/` : 転写テキスト
- `results/` : 実行結果JSON
- `grok_tts_outputs/` : SBV2/Grokの中間生成物（保存設定に応じて削除）

## 6. 設定ファイル

- パス: このフォルダ直下の `config.json`
- 設定変更時に自動保存
- 手編集する場合はUTF-8で編集

## 7. よくある確認

- 反応しない: `KKS起動中` がONか
- 外部テキストが来ない: `source_mode` が `mic` になっていないか
- 音声ファイルが残らない: 音声保存2項目がOFFのままではないか
